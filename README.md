# islami
Islami App is a modern Flutter application designed to help you stay connected to your faith. It provides essential tools like prayer times and live radio with a clean, Built with a focus on a responsive UI, smooth animations, MVVM Architecture , Cubit

## ✨ Features  
- **Prayer Section**: Location-based prayer times with a live countdown timer.
- **Radio Section**: Searchable Islamic stations with dynamic audio wave animations
- **Tasbih Section**: Interactive Zikir counter with a simple and smooth experience.
- **Azkar Details**: Morning and Evening Azkar in a clean, readable layout.
- **Responsive Layout**: Fully scaled for all mobile devices using ScreenUtil.
- **State Logic**: High performance and smooth logic using Cubit.

## 🚀 Getting Started

### Prerequisites
- Flutter SDK (latest version)
- Dart SDK (latest version)
- Android Studio / VS Code

### Installation
1. Clone the repository:
```bash
git clone https://github.com/hatemf934/islami
```

2. Navigate to the project directory:
```bash
cd islami
```

3. Install dependencies:
```bash
flutter pub get
```

4. Run the app:
```bash
flutter run
```
